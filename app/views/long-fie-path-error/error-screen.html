There is a problem with your files

Some records could not be uploaded because their filepath is too long.

This usually happens when a file is stored inside several nested folders on a Windows computer.

What to do next

Trying one of these options should allow the files to be uploaded:

  • Reopen TDR on an Apple Mac, or a Linux computer, and start your transfer again.
  • Move the file closer to the top-level folder, shorten folder names, or shorten the file name, then try again. Identify these files with this tool .
